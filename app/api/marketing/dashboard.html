How to use, update & share

Editing (your team): click 🔧 Edit mode (top-right). You can then add, ✎ edit and 🗑 delete calendar events, partners and LinkedIn posts. Changes save automatically in your browser (localStorage).

Sharing edits with everyone (important): browser storage is per-person, so your edits aren't automatically seen by colleagues. To publish changes to the shared dashboard: in Edit mode click ⬇ Export data, then either (a) hand the JSON to whoever redeploys the site (replace data.json / the defaults and redeploy), or (b) share the file so colleagues click ⬆ Import. ↺ Reset restores the last published version.

Want true real-time shared editing (everyone sees updates live)? That needs a shared backend — the cleanest options are a Google Sheet or Airtable the team edits with the dashboard reading from it, or a small database. Ask Claude to wire one of these up and this becomes a live multi-user tool.

⏭️ Flagged next step — shared promo approval: the 🏷️ Promos Status (approve/schedule) and Dropbox links currently save in your browser, so approvals aren't yet shared across the team. To make approval a real multi-person workflow (everyone sees the same approved state), deploy with a shared backend — an Airtable/Google Sheet or small database holding the promos, with the dashboard reading/writing to it. Until then, run single-approver and use ⬇ Export / ⬆ Import to sync.

Gantt roadmap: the 📊 Gantt tab shows the whole year — promo campaigns, partner flights and owned channels as timeline bars. Use Download SVG (crisp, scalable) or Download PNG to drop it into decks, emails or print.

Deploy: host the bundle on Vercel/Netlify. For team-only access use Vercel Authentication (Settings → Deployment Protection) or Netlify password protection. See the README in the deploy bundle.
